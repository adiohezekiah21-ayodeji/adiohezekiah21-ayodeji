## 👨🏽‍💻 About Me

I'm a **front-end web development intern** who turns design mockups into clean, responsive, functional websites. I care about tidy structure, consistent design systems, and layouts that hold up on every screen size.

- 🔭 **Currently working on:** an e-commerce website for a tech-products organization (React), a weather app (React + Tailwind CSS), and **QueueLess**, a university queue-management system
- 🎨 **What I do best right now:** converting Figma designs into pixel-faithful static sites with semantic HTML and well-organised CSS (custom properties, Flexbox, Grid, responsive layouts)
- 🌱 **Currently levelling up:** JavaScript, React, Tailwind CSS, and backend basics with Node.js and Express
- 🤝 **How I work:** I collaborate with other developers through Git and GitHub, including multi-person projects where each teammate owns a page

<summary><b>🔍 How I build: my standards (click to expand)</b></summary>

- **Design-to-code fidelity:** I work from Figma and match spacing, typography, and colour tokens closely.
- **Maintainable CSS:** Shared stylesheets and CSS custom properties instead of repeated values.
- **Responsive by default:** Mobile layouts are planned alongside desktop ones, using Flexbox and Grid.
- **Lightweight interactions:** Where it makes sense, I use pure CSS (for example, radio/checkbox techniques for carousels and mobile menus) before reaching for JavaScript.
- **Team workflow:** Branches, commits, and merges through GitHub when working with others.
